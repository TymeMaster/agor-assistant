### Findings

[12:00] Rate limit detection research:
  - `claude -p --output-format stream-json --verbose` emits `rate_limit_event` JSON line
  - Fields: status (allowed/rejected), isUsingOverage, overageStatus, resetsAt, overageResetsAt
  - `--bare` flag suppresses rate_limit_event — cannot use it
  - Must run from /tmp to avoid CLAUDE.md triggering full agent startup (timeout)

  - Verified on both "allowed" and "rejected" (5h limit hit) states
