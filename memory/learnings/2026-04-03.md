# Learnings: 2026-04-03

## Codex sessions — spawn vs create

`agor_sessions_spawn` s Codex nefunguje pro file edits ani analýzu — vrátí 0 tool uses a okamžitě selže. Spawn zdědí parent worktree ale Codex v tom kontextu nemá přístup k nástrojům.

Pro Codex s file access: vždy `agor_sessions_create` se správným `worktreeId`.

## Codex auth de-sync

Po manuálním `codex login` v terminálu daemon drží starý refresh token → `401` nebo "refresh token already used". Fix: `codex logout && codex login` jako user agor. Daemon načte nový token automaticky.

Diagnostika: `grep "Codex execution failed" /home/agor/.agor/logs/daemon.log | tail -5`

## agor_sessions_list boardId filter

`agor_sessions_list` s `boardId` filtrem vrací `data: []` i když `total: 61`. Filter nefunguje. Workaround: listovat bez filtru a filtrovat lokálně podle `worktree_board_id`. Zaznamenat do skills/agor-state-sync.md jako known issue.
